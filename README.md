# StampBook

A browser-based travel stamp generator. Create passport-style stamps (circular or rectangular), place them on a passport page and export the page as a PNG.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Stack
React 19 · Vite · Tailwind CSS 4 · Zustand · plain SVG (ink texture via feTurbulence filters). No backend.

See `WORKFLOW.md` for the folder structure and how the pieces fit together.
