# How it works
1. The store holds an array of stamps `{ id, city, country, date, icon, shape, ink, x, y, rot, size }`.
2. The Sidebar edits whichever stamp is selected; changes render live on the page.
3. Ink texture: each stamp gets its own SVG filter. A low-frequency noise map displaces the edges, and a high-frequency noise map masks out speckles of ink.
4. Dragging converts pointer coordinates to SVG coordinates with `getScreenCTM().inverse()`.
5. Export clones the page SVG, removes the selection outline, draws it to a 1600×2200 canvas and downloads the PNG.
